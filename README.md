# 📊 Super Store Sales & Profit Dashboard — Excel

An interactive **Super Store Dashboard built in Microsoft Excel** to analyze sales, profitability, profit margins, product categories, and regional performance.

The project demonstrates an end-to-end Excel analytics workflow using **Power Query, Power Pivot, DAX, PivotTables, Pivot Charts, slicers, filters, and interactive dashboard design**.

---

## 📌 Project Overview

The objective of this project is to transform raw Super Store sales data into an interactive business intelligence dashboard that helps users quickly understand:

- Overall sales performance
- Total profit and profitability
- Profit margin
- Category-level profitability
- Regional performance
- Underperforming and high-performing product categories
- Key business trends and performance indicators

The dashboard is designed for **management reporting and business decision-making**, allowing users to interactively filter the analysis by **Region** and **Category**.

---

## 🎯 Project Objectives

The key objectives of this project are:

1. Clean and transform raw sales data using **Power Query**.
2. Build a structured analytical data model using **Power Pivot**.
3. Create reusable business calculations using **DAX measures**.
4. Analyze sales and profitability across different business dimensions.
5. Build interactive Pivot Charts and dashboard visualizations.
6. Enable dynamic analysis using **Slicers and Filters**.
7. Present important KPIs in a simple management-friendly dashboard.
8. Identify profitable and loss-making product categories.
9. Create an Excel dashboard that can be used for recurring business reporting.

---

## 🏢 Business Operations

The dashboard represents a retail/super-store business where products are sold across multiple regions and categories.

### Business dimensions

The analysis focuses on:

| Dimension | Description |
|---|---|
| Region | Geographic area where sales are generated |
| Category | Major product groups |
| Sales | Revenue generated from customer orders |
| Profit | Profit generated after costs |
| Profit Margin | Profit as a percentage of sales |
| Orders | Customer/order activity |
| Products | Products contributing to sales and profit |

### Product Categories

The dashboard analyzes three major categories:

- **Furniture**
- **Office Supplies**
- **Technology**

### Regions

The dashboard supports analysis across:

- Central
- East
- South
- West
